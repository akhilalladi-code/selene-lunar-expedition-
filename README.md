# SELENE — Lunar Expedition

**Repository description:** A cinematic, multi-page speculative lunar exploration concept website built with responsive HTML, CSS and JavaScript, ready for GitHub Pages.

SELENE is an original rebuild created from the project concept because the original ZIP, source files and image assets were not available. It is not a recovery of the previous implementation.

## Experience
- Cinematic lunar-inspired hero scene built in CSS
- Multi-page navigation: Overview, The Mission and Expedition
- Responsive layouts and mobile navigation
- Motion-reduced-by-default friendly progressive enhancement (scroll reveals only when IntersectionObserver is available)
- Search/social metadata and semantic page structure
- Relative asset paths for GitHub Pages project hosting

## Tech
- HTML5
- CSS (custom design system, no framework)
- Vanilla JavaScript
- Google Fonts (DM Mono and Manrope; system fallbacks included)

## Run locally
Open `index.html` in a browser or serve the folder with any static HTTP server.

## Deploy to GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/(root)`, then save.
4. Wait for the Pages build to finish.

A workflow is also included to publish the root directory with GitHub Actions.
